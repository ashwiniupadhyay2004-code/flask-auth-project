# 🔐 Flask Authentication Project

A simple full-stack authentication web application built using **Flask**, **SQLite**, and **HTML**.

This project allows users to:

* Create an account (Signup)
* Log in securely
* Access a dashboard
* Log out safely

---

## 🚀 Live Demo

👉 https://flask-auth-project-medn.onrender.com

---

## 📌 Features

* ✅ User Signup
* ✅ User Login
* ✅ Secure Password Hashing
* ✅ Session Management
* ✅ Protected Dashboard
* ✅ Logout Functionality

---

## 🛠️ Tech Stack

* **Backend:** Python + Flask
* **Frontend:** HTML
* **Database:** SQLite
* **Deployment:** Render
* **Version Control:** Git + GitHub

## ⚙️ Installation

### Clone repository

```id="jlwmcr"
git clone https://github.com/ashwiniupadhyay2004-code/flask-auth-project.git
cd flask-auth-project
```

---

### Install dependencies

```id="o0johx"
pip install -r requirements.txt
```

---

### Run project

```id="wy2fe1"
python app.py
```

---

### Open browser

```id="n7frp4"
http://127.0.0.1:5000
```

## 🔐 Security

Passwords are securely hashed using:

* `generate_password_hash()`
* `check_password_hash()`

from Werkzeug.
